# Закрытый пилот электронных книг

Доступ только для активных Buyer/Seller с email `ronnie83@mail.ru` и сессии
главного администратора `main_admin_authenticated=True`. Все маршруты, прогресс,
предпросмотр и PDF проверяют доступ на сервере. Гость и другие аккаунты получают
404. `DIGITAL_BOOKS_PILOT_ENABLED=False` закрывает раздел целиком.

* `/digital/manage`: загрузка EPUB/PDF до 15 МБ, черновик, предпросмотр,
  публикация и снятие с продажи. Управляет только согласованный продавец/админ.
* `/digital/books`: отдельная витрина, отсутствующая в обычном каталоге.
* `/digital/library`: только собственные оплаченные книги.
* EPUB: текстовая читалка с оглавлением, темами, размером шрифта и сохранением
  главы/позиции. Издательский HTML не исполняется; иллюстрации и исходная вёрстка
  EPUB в этой первой версии не воспроизводятся.
* PDF: встроенный просмотр браузером, сохранение закладки по указанному номеру
  страницы. Изменение страницы внутри браузерной PDF-панели не считывается.

Книги хранятся в `<UPLOAD_FOLDER>/.private/books` на существующем постоянном
томе. Статическая раздача `.private` уже запрещена приложением. Запросы книг
возвращаются с `private, no-store`. PDF передаётся браузеру для чтения, поэтому
защита не является DRM и не обещает запрет копирования/скачивания.

Новые таблицы `digital_books` и `digital_purchases` добавляются через `db-init`
или миграцию `d36e58f0a417`, предыдущая ревизия `c25d47e9f306`. Таблицы физических
товаров не меняются. Схема отката не удаляет покупки и файлы.

Покупка одной книги создаёт отдельный скрытый заказ с нулевой доставкой. Сумма
берётся из БД, применяется существующая Robokassa и её проверка подписанного
ResultURL. Только рабочий платёж со статусом `paid` открывает книгу. Возврат
браузера, тестовый платёж или неоплаченный счёт доступа не дают. Чужая корзина,
остатки и физическая доставка не используются и не изменяются. Публикация книги
не влияет на существующие покупки: имя файла и название фиксируются в покупке.
Снятие с продажи сохраняет доступ покупателю; отменённый заказ доступа не даёт.

Не включать пилот для остальных пользователей и не менять список допуска без
отдельного решения владельца. Для проверки читалки без реального списания есть
предпросмотр продавца/админа; платные права и callback тестируются локально на
SQLite с вымышленными ключами. Производственные платежи не подделывать.
